Gemini module for *pyobs*
==========================

This is a [pyobs](https://www.pyobs.org) module for
[Optec Gemini](https://www.optecinc.com/astronomy/catalog/gemini/) focuser/rotator units,
connected over a serial line.


Install *pyobs-gemini*
------------------------
Clone the repository:

    git clone https://github.com/pyobs/pyobs-gemini.git
    cd pyobs-gemini

Install it with [uv](https://docs.astral.sh/uv/):

    uv sync
